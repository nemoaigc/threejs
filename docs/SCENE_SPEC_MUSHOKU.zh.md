# 无职转生主题 · 场景规格书（平面优先）

> 施工单 / 资产与布局规格。画风对齐本项目 **cel + 描边 + 色阶**（Messenger 味），主题借用《无职转生》早期 **布埃纳 / 罗亚乡间城镇** 叙事地标，**不是**原作写实管线 1:1 复刻，也不是魔法都市夏利亚整城。  
> 关联实现：`src/world.js`（布局 populate / plant / sole@y=0）、`src/layouts/mushoku-slice-p0.js`、`src/content/*` + `src/entities/*`、`docs/CONTENT_PIPELINE.zh.md`、`docs/HOW_IT_WORKS.zh.md`、`README.md`。  
> 旧规格：`SCENE_SPEC_LOVE_AND_DEEPSPACE.zh.md`（恋与深空 / 临空切片，已退役叙事，仅作历史对照）。

## 1. 一句话场景命题

**无职转生早期乡间的「村庄日常切片」**——十字土路 + 冒险者公会 + 神殿/教堂 + 旅馆，不是整座开放世界，更不是夏利亚魔法大学城。

叙事钩子（玩家 3 秒内应感到）：*木石小镇、公会接委托、神殿尖顶与彩窗、马车驿站，温柔的奇幻日常。*

## 2. 明确不做

| 不做 | 原因 |
|------|------|
| 写实皮肤 / 电影级 PBR / SSS | 管线是 cel+outline+posterize |
| 整城开放世界 / 夏利亚 mega | 切片 demo，内容预算有限 |

| 随机密铺、全贴 (0,0)、同体量盒子冒充神殿 | 布局纪律硬禁止 |
| 高面数「堆面当精致」 | Messenger 精致 ≠ 面数 |

## 3. 英雄镜头（Hero shot）

- **站位**：十字广场偏南约 **(0, 0, 6)**，角色朝北（−Z）。
- **相机**：眼高约 1.4–1.6m，略俯，看向 **(0, 2.5, −8)** 一带。
- **剪影层次（近 → 远）**：
  1. 近：土路 / 广场铺装 + 木灯笼；马车驿站棚。
  2. 中左：**冒险者公会**（木石、大招牌、告示板、双开门）。
  3. 中右：**旅馆**（暖木、悬挂招牌、底楼酒馆窗）。
  4. 中轴远端：**神殿/教堂**（白石中殿 + 钟楼尖顶 + 彩窗 + 太阳徽）。
  5. 远景：2–4 座城堡/城塞剪影。
  6. 天空：干净渐变；全场景统一一时段。

### 验收关键词（3 秒）

「冒险者公会 / 奇幻小镇 / 神殿」或「旅馆 + 魔法店的乡间街角」——不合格：只能说出「一堆方盒子」。

## 4. 空间布局纪律

与旧临空切片相同的呼吸规则：

| 区 | 功能 |
|----|------|
| A 主街 | 东西主干 + 沿街店（魔法道具店 / 铁匠 / 杂货） |
| B 广场 | 水井、任务告示板、灯笼；**禁止中心种大楼** |
| C 地标 | 公会西/西北；神殿北/东北；旅馆东 |
| D 远景 | 城塞 + 坡顶民居剪影 |

硬性禁止：随机密铺、全贴 (0,0)、同体量盒子冒充神殿/公会、单块超长马路 mesh。

声明式布局：`src/layouts/mushoku-slice-p0.js` → `populateFromLayout`。
